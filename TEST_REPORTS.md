# Test Reports and Coverage

## Overview

This document describes the test reports generated by the project, including unit tests, integration tests, and E2E tests. Test reports are generated automatically during CI/CD and can be viewed locally.

## Test Types and Reports

### 1. Unit Test Reports

**Location:** `<module>/build/reports/tests/testDebugUnitTest/index.html`

**Coverage:**
- Core modules (logger, IPC, common)
- Domain layer use cases
- Data layer repositories
- ViewModels

**Report Contents:**

- Test execution time

open location/domain/build/reports/tests/testDebugUnitTest/index.html

**Location:** `<module>/build/reports/androidTests/connected/index.html`

**Coverage:**

**Run Integration Tests:**

### 3. E2E Test Reports

**Location:** `internet/app/build/reports/androidTests/connected/index.html`

**View Report:**

## CI/CD Test Reports

### GitHub Actions Integration

Tests run automatically on every push and pull request. Reports are uploaded as artifacts.

**Workflow Steps:**
```yaml
- name: Run tests
  run: ./gradlew test --continue

- name: Upload test results
  uses: actions/upload-artifact@v4
  with:
    name: test-results
    path: '**/build/test-results/test*/*.xml'
    retention-days: 90

- name: Upload test reports
  uses: actions/upload-artifact@v4
  with:
    name: test-reports
    path: '**/build/reports/tests/'
    retention-days: 90
```

**Accessing CI Reports:**
1. Go to GitHub Actions run
2. Scroll to "Artifacts" section
3. Download `test-results` or `test-reports`
4. Extract and open `index.html` files

**Retention:** Reports kept for 90 days

### Test Report Formats

**JUnit XML (for CI):**
```
<module>/build/test-results/testDebugUnitTest/*.xml
```

**HTML (for humans):**
```
<module>/build/reports/tests/testDebugUnitTest/index.html
```

**Coverage XML (for SonarQube, etc.):**
```
<module>/build/reports/jacoco/test/jacocoTestReport.xml
```

- Verify upload-artifact step executed
- Check retention period (reports expire after 90 days)
